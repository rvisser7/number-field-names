# Pretty names data

_This folder is work-in-progress_

One file per degree, `degree<n>.txt`, in psycodict upload format:
a header line `label|pretty_name`, a types line `text|text`, a blank line,
then one row per field.

- `label` is the LMFDB number field label, e.g. `2.0.3.1`.
- `pretty_name` is the LaTeX name, without `\(` `\)`, e.g. `\Q(\sqrt{-3})`.

Rows are in the same order as on the LMFDB: by absolute discriminant, then discriminant sign
(negative first), then iso number. For example `2.0.8.1` comes before `2.2.8.1`, which comes before `2.0.11.1`.
Fields without a name are left out.

`degree2.txt` currently covers the fundamental discriminants with $|D| \leq 1000$, generated by
`python3 scripts/generate_degree2.py --bound 1000`.
